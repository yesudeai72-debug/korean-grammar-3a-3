# 한국어 3A · 2과 문법 ③

질문과 대답을 그림 힌트로 연결하는 웹앱입니다.

- index.html을 브라우저로 열면 실행됩니다. style.css, app.js, favicon.svg를 함께 보관하세요.
- 질문 → 그림 → 대답 순서로 하나씩 눌러 세 개를 고르면 자동으로 선이 연결됩니다.
- 이미 연결된 항목을 다시 누르면 연결이 풀려서 다시 고를 수 있습니다.
- 정답 확인: 지금까지 만든 연결이 맞는지 초록/빨강으로 표시하고 맞은 개수를 보여줍니다.
- 정답 보기: 정답 연결을 모두 자동으로 그려줍니다.
- 다시 하기: 모든 연결을 지우고 처음부터 다시 풉니다.
- 하단의 "나만의 질문" 입력칸은 채점 대상이 아닌 자유 작문 연습용입니다.
- 모바일 화면에서는 선 대신 색상으로 연결 상태를 표시합니다.
- GitHub Pages에 올릴 때는 이 폴더의 파일 구조를 그대로 유지합니다.
