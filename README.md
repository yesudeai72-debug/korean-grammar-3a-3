# 한국어 3A · 2과 문법 ③ (-느라(고))

두 단계로 구성된 웹앱입니다.

## 1단계 · 그림으로 문장 찾기
- 질문과 대답을 그림(아이콘 4개로 만든 장면 + 명사 라벨) 힌트로 연결하는 활동입니다.
- 질문 → 그림 → 대답 순서로 하나씩 누르면 세 개가 자동으로 연결됩니다.
- 이미 연결된 항목을 다시 누르면 연결이 풀립니다.
- 정답 확인 / 정답 보기 / 다시 하기, 점수 표시를 지원합니다.
- 그림 라벨은 모두 명사형으로만 되어 있어 목표 문법(-느라(고))이 드러나지 않습니다.
- 하단의 "나만의 질문" 입력칸은 채점 대상이 아닌 자유 작문 연습용입니다.

## 2단계 · '-느라(고)' 만들기
- 1단계의 여섯 상황을 문장 6개로 번호를 매겨 제시합니다.
- 각 문장 가운데에는 점선 상자(기본형, 예: 게임하다)가 있습니다.
- 점선 상자를 클릭하면 기본형이 사라지고 빈 입력칸으로 바뀌어, 학생이 직접
  "기본형 + -느라(고)" 결과물(예: 게임하느라고)을 스스로 만들어 써야 합니다.
- "느라고"와 "느라" 두 형태 모두 정답으로 인정합니다.
- 정답 확인 / 정답 보기 / 다시 하기, 점수 표시를 1단계와 동일하게 지원합니다.
- 상단 "처음부터" 버튼은 1단계와 2단계를 모두 초기화합니다.
